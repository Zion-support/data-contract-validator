# Data Contract Validator

Validate data contracts between producers and consumers: schema drift detection, breaking-change alerts and SLA checks for your data products.

**Live app:** https://zion-support.github.io/data-contract-validator/

## Features
- Schema & contract validation (JSON Schema / Avro / Protobuf)
- Breaking-change detection between versions
- SLA and freshness assertions
